# Структура репозитория

## Главные директории

### `/topics`
Основной контент проекта. Каждая подпапка — отдельная тема.

```
topics/
├── 01-ai-intelligence-overview/
│   └── README.md (полное содержание темы)
├── 02-espidf-testing/
│   └── README.md
├── 03-qwen-coder-guide/
│   └── README.md
├── 04-z-ai-secrets/
│   └── README.md
├── 05-ai-agents-development/
│   └── README.md
└── 06-grok-integration/
    └── README.md
```

Каждый README содержит:
- Введение в тему
- Ключевые концепции
- Практические примеры
- Советы и рекомендации
- Контроль качества

### `/examples`
Практические примеры, шаблоны, конфиги.

```
examples/
├── espidf/
│   └── ci-build.yml (GitHub Actions для ESP-IDF)
├── prompts/
│   └── qwen-coder-template.md (шаблон запроса)
└── agent/
    └── agent-prompt-template.md (шаблон для агентов)
```

### `/workspace`
Локальное рабочее окружение.

```
workspace/
├── apps/          # ваши приложения
├── scripts/       # служебные скрипты
└── README.md      # инструкция по настройке
```

### `/docs`
Архитектурная и методологическая документация.

```
docs/
├── architecture.md     # архитектура проекта
├── repo-structure.md   # эта файл
└── workflow.md         # рекомендуемый рабочий процесс
```

## Ветки в репозитории

### main
Залив всех готовых тем. Содержит финальное, проверенное содержание.

### Тематические ветки
Каждая тема разрабатывается в отдельной ветке:
- `01-ai-intelligence-overview`
- `02-espidf-testing`
- `03-qwen-coder-guide`
- `04-z-ai-secrets`
- `05-ai-agents-development`
- `06-grok-integration`

В ветке может быть:
- Расширенные материалы
- Черновики
- Экспериментальный код
- Дополнительные примеры

## Файловое соглашение

### Названия файлов
- Документы: `lowercase-with-dashes.md`
- Код: `lowercase_with_underscores.py`
- Конфиги: `UPPERCASE-or-config.yml`

### Размер контента
- README в каждой папке: 2000-5000 символов
- Примеры: полный рабочий код
- Без ненужных зависимостей

## Что должно быть в каждой теме

✅ Введение
✅ Ключевые концепции (3-5)
✅ Практические примеры
✅ Чек-лист или рекомендации
✅ Вопросы для размышления
✅ Итоговая мысль

## Как навигировать
1. Начните с `README.md` в корне
2. Выберите нужную тему
3. Внутри темы `topics/XX-*/` найдите `README.md`
4. Примеры код ищите в `examples/`
5. Для работы локально — используйте `workspace/`
