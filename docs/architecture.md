# Архитектура проекта AI Smart Topics

## Общая философия
Это не просто "сборник статей". Это **структурированная база знаний**, где:
- каждая тема автономна и может изучаться отдельно;
- есть явные зависимости между темами (основы → специализация);
- каждая тема содержит практические примеры;
- есть примеры использования для каждого инструмента.

## Слои проекта

### 1. Основы (Foundation)
- `topics/01-ai-intelligence-overview/` — базовое понимание ИИ
- Читается первым
- Объясняет концепции

### 2. Технологии и инструменты (Tools & Technologies)
- `topics/02-espidf-testing/` — ESP-IDF и embedded
- `topics/03-qwen-coder-guide/` — Qwen Coder
- `topics/04-z-ai-secrets/` — Chat Z.ai
- `topics/06-grok-integration/` — Grok

Каждая может изучаться независимо.

### 3. Архитектура систем (Architecture)
- `topics/05-ai-agents-development/` — AI-агенты
- Требует понимания основ (тема 1)
- Может использовать знания из тем 2-4

### 4. Примеры и практика (Practice)
- `examples/` — шаблоны, конфиги, промпты
- `workspace/` — локальное окружение для экспериментов

## Почему такая структура
1. **Модульность** — каждую тему можно брать отдельно
2. **Прогрессивность** — от простого к сложному
3. **Практичность** — каждая тема имеет примеры
4. **Масштабируемость** — легко добавлять новые темы

## Где хранится контент
- **Основной контент** → `topics/*/README.md`
- **Примеры кода** → `examples/*/`
- **Архитектурные решения** → `docs/`
- **Рабочее окружение** → `workspace/`

## Как добавлять новый контент
1. Создайте ветку `XX-topic-name`
2. Добавьте папку `topics/XX-topic-name/`
3. Напишите `README.md` с полным содержанием
4. Добавьте примеры в `examples/` если нужно
5. Сделайте PR и объедините в main
